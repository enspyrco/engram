Where the design came from

Ingesting a course about agent skills produced an agent skill for ingesting courses.

Writing down that skill’s scheduling rules is where the FSRS insight surfaced. A system built to find connections found one about itself.

The origin is a nice recursion. An eleven-video Anthropic course on agent skills was the test material. Ingesting it made it obvious that the ingestion pipeline should itself be an agent skill, and spelling out the scheduling constraints for that skill is what revealed that FSRS could take Claude’s difficulty prediction, closing the loop we just saw. The repo has the full story in docs/ORIGIN_STORY.md.
