The marker goes line by line. Each line is met, partial or missed. It also watches for misconceptions: things you said that are wrong, like “sound is faster”. Then a fixed rule turns the ticks into the same buttons you used to press yourself. Our answer clearly says light is faster, but only implies they start together, so it gets Hard: you knew it, with a gap. The marker never awards Easy; that stays a human judgement.
