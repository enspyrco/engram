Now there’s nothing fuzzy to get wrong. The marker copies your words and says where they start; the code checks both, letter for letter. First reply: correct, so the credit counts. Second: those words aren’t in the answer at all; the marker made them up, so the marking fails. Third: right words, wrong position. Models copy well but count badly, so this will happen, and it fails rather than guessing. Why the position at all? Because an answer can contain the same words twice, like “Paris is wrong. Paris is correct.” and only one of them earns the mark. The number says which.
